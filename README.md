# M. Zakaullah — Professional Portfolio Website

A high-performance, responsive personal portfolio website for **M. Zakaullah**, Senior Web Developer and AI Solutions Engineer. Designed with a premium minimalist aesthetic, smooth micro-interactions, responsive grids, and interactive web components.

## 🚀 Live Demo & Positioning
The site positions you as a **Senior Web Developer delivering faster, smarter solutions with AI-powered workflows**. It highlights your expertise in WordPress theme customizations, Next.js / Astro custom frameworks, web optimization, and modern AI tool integrations.

---

## ✨ Features

- 🌓 **Dynamic Dark Mode**: Respects system preferences and includes an interactive toggle button with smooth CSS transitions.
- 🚀 **AI-Assisted Workflow Highlight**: Details how you combine human developer judgment with 10x AI code generations (Cursor, Claude, Copilot, ChatGPT).
- 🧩 **Interactive Tech Stack Tabs**: Custom Web Component panel displaying Core Stack (Next.js, Astro, PHP, MySQL), AI Tools, and Why Choose Me checklists.
- 📱 **6-Card Bento Service Grid**: Responsive service layouts representing AI-Powered Web Dev, WordPress page builders (Divi/Elementor), Speed Performance and SEO audits.
- 🎠 **Scroll-Driven Testimonials Carousel**: Uses native CSS `view-timeline` and `animation-timeline` to create scroll-snap card scaling, with an optimized JavaScript fallback for Firefox/older browsers.
- 📝 **Interactive Contact Form**: Custom floating input label animations, client budgets, copy-to-clipboard email integration, and real-time form validation.
- 🌐 **Responsive Design**: Designed mobile-first, rendering perfectly across all screens (iPhone, iPad, Desktop).

## 💻 Getting Started

Follow these steps to run the portfolio website locally on your machine:

### 1. Prerequisites
Ensure you have **Node.js** (v18+) installed.

### 2. Installation
Clone the repository and install the project dependencies:
```bash
git clone https://github.com/kocokk2017/explore-pakistan-spark.git
cd explore-pakistan-spark
npm install
```

### 3. Development Server
Start the local Vite server:
```bash
npm run dev
```
Open **`http://localhost:5173`** in your browser to view the site.

### 4. Build for Production
Generate the optimized static assets ready for hosting:
```bash
npm run build
```
The output will be saved inside the `dist/` folder, ready for deployment to Vercel, Netlify, or Github Pages.
